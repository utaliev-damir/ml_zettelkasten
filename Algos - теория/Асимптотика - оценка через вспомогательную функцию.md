## Идея

Доказать $f(n) \le g(n)$ — то же, что доказать $h(n) = g(n) - f(n) \ge 0$. Функция $h$ не придумывается, это просто «правая часть минус левая».

Чтобы показать $h \ge 0$ при $n \ge n_0$, достаточно двух фактов:

- в точке $n_0$ значение $h(n_0) \ge 0$;
- дальше $h$ только растёт: $h'(x) \ge 0$ при $x \ge n_0$.

Как дорога: стартуем не ниже нуля и всё время идём вверх — ниже нуля не опустимся.

## Когда применять

Когда сравниваются функции разной природы (логарифм против корня, логарифм против $n$), и простое «увеличение слагаемых» не работает.

## Шаги

1. Поделить на общий множитель, чтобы осталось простое неравенство (например, $\log_2 n \le \sqrt{n}$).
2. Составить $h(x) = (\text{правая}) - (\text{левая})$.
3. Решить неравенство $h'(x) \ge 0$ — найти, где $h$ растёт.
4. Найти точку $x_0$ на участке роста, где $h(x_0) \ge 0$. Если уравнение $h = 0$ не решается формулой — подбирать среди удобных чисел (где обе части целые).
5. Вывод: $h(n) \ge 0$ при $n \ge x_0$, значит $n_0 = x_0$.

## Пример: $n\log n = O(n^{3/2})$

Делим на $n$: нужно $\log_2 n \le \sqrt{n}$. Пусть $h(x) = \sqrt{x} - \log_2 x$.

$$h'(x) = \frac{1}{2\sqrt{x}} - \frac{1}{x\ln 2} \ge 0 ;\Longleftrightarrow; \sqrt{x} \ge \frac{2}{\ln 2} ;\Longleftrightarrow; x \ge \left(\frac{2}{\ln 2}\right)^2 \approx 8{,}3$$

Ищем, где $h$ возвращается к нулю после 8,3. Подбором среди степеней четвёрки: $\sqrt{16} = 4 = \log_2 16$, значит $h(16) = 0$.

При $n \ge 16$: $h$ растёт и $h(16) = 0$, поэтому $\log_2 n \le \sqrt{n}$, и $n\log_2 n \le n^{3/2}$.

**Ответ:** $C = 1$, $n_0 = 16$.

## Подводные камни

- Функция может уходить ниже нуля на начальном участке: здесь $h(8) \approx -0{,}17$, неравенство неверно при $n = 5,\dots,15$. Поэтому $n_0$ нельзя брать произвольно маленьким.
- Брать можно любую точку $\ge 16$, выбирают самую удобную для счёта.

## Альтернатива без производной

Иногда хватает индукции. Например, $\log_2 n \le n \iff n \le 2^n$:

- база: $1 \le 2$;
- шаг: $n + 1 \le 2^n + 1 \le 2^n + 2^n = 2^{n+1}$.
