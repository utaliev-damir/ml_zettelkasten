# Подсчёт операций во вложенных циклах

Все шаги алгоритма — это таблица: **строки** = значения внешнего $i$,
**столбцы** = шаги внутреннего цикла. $T(n)$ = число закрашенных клеток.
Считать можно по строкам или по столбцам — ответ одинаковый.

---

## Порядок A: по строкам (через внешний цикл)

1. Зафиксировать одно $i$.
2. Посчитать, сколько раз выполнится внутренний цикл при этом $i$ → $k(i)$.
3. Сложить по всем $i$: $T = k(1) + k(2) + \dots + k(n)$.
4. Упростить сумму. Если не получается — оценить сверху и снизу.

👉 Удобно, когда $k(i)$ простое (например $n - i$).

## Порядок B: по столбцам (через внутренний шаг)

1. Записать, чему равна переменная внутреннего цикла на шаге $r$ (через $i$ и $r$).
2. Записать условие, при котором этот шаг выполняется (условие цикла).
3. Решить неравенство относительно $i$: получить $i \le \dots$ или $i \ge \dots$
4. Сосчитать, сколько $i$ подходит (с учётом границ внешнего цикла;
   $i$ целое → граница округляется вниз) → $c(r)$.
5. Найти последний непустой столбец (подставить самое «удачное» $i$).
6. Сложить по всем $r$: $T = c(0) + c(1) + \dots$ и упростить.

👉 Удобно, когда $k(i)$ сложное (логарифмы), а условие шага простое.

---

## Пример 1 (простой)

```python
for i in range(1, n + 1):
    for j in range(i, n + 1):
        op()
```

Таблица для $n = 4$ (■ = шаг выполнен, столбец = значение $j$):

| i \ j | 1 | 2 | 3 | 4 | в строке |
|---|---|---|---|---|---|
| 1 | ■ | ■ | ■ | ■ | 4 |
| 2 |   | ■ | ■ | ■ | 3 |
| 3 |   |   | ■ | ■ | 2 |
| 4 |   |   |   | ■ | 1 |
| в столбце | 1 | 2 | 3 | 4 | **10** |

**Порядок A:**
1–2. При данном $i$ внутренний цикл идёт от $i$ до $n$ → $k(i) = n - i + 1$.
3. $T = n + (n-1) + \dots + 1$.
4. $T = \dfrac{n(n+1)}{2}$.

**Порядок B:**
1. Столбец = значение $j$.
2. Шаг с этим $j$ есть, если $i \le j$ (цикл начинается с $i$).
3–4. Подходят $i = 1, 2, \dots, j$ → $c(j) = j$.
3. Последний столбец $j = n$.
4. $T = 1 + 2 + \dots + n = \dfrac{n(n+1)}{2}$.

**Итог:** $T(n) = \Theta(n^2)$, оба способа дали одно и то же.

## Пример 2

```python
for i in range(1, n + 1):
    j = i
    while j < n:
        j *= 2
```

Таблица для $n = 17$ (в клетке — значение $j$):

| i | r=0 | r=1 | r=2 | r=3 | r=4 | в строке |
|---|---|---|---|---|---|---|
| 1 | 1 | 2 | 4 | 8 | 16 | 5 |
| 2 | 2 | 4 | 8 | 16 | | 4 |
| 3–4 | i | 2i | 4i | | | 3 |
| 5–8 | i | 2i | | | | 2 |
| 9–16 | i | | | | | 1 |
| 17 | | | | | | 0 |
| в столбце | 16 | 8 | 4 | 2 | 1 | **31** |

**Порядок A:**
1–2. $j$ удваивается от $i$ до $n$ → $k(i) \approx \log_2(n/i)$, у каждого $i$ своё.
3. $T = 5 + 4 + 3 + 3 + 2 + 2 + 2 + 2 + 1 + \dots$ — неудобно.
4. Грубо: «каждое $i$ делает $\le \log n$ шагов» → $T \le n \log n$. Верно, но **завышено**.

**Порядок B:**
1. На шаге $r$: $j = i \cdot 2^r$.
2. Шаг есть, если $i \cdot 2^r < n$, то есть $i \cdot 2^r \le n - 1$.
3. $i \le \dfrac{n-1}{2^r}$.
4. $c(r) = \left\lfloor \dfrac{n-1}{2^r} \right\rfloor$. Для $n = 17$: $16, 8, 4, 2, 1$.
5. Последний столбец, где есть $i = 1$: $2^r \le n - 1$ → $r = \lfloor \log_2(n-1) \rfloor$.
6. Складываем и оцениваем:
$$T = \sum_{r=0}^{\lfloor \log_2(n-1) \rfloor} \left\lfloor \frac{n-1}{2^r} \right\rfloor \le (n-1)\left(1 + \frac12 + \frac14 + \dots\right) = 2(n-1)$$
   Снизу $T \ge n - 1$ (первый столбец).

**Итог:** $T(n) = \Theta(n)$, а не $\Theta(n \log n)$.

---

## Полезные суммы

- $1 + 2 + \dots + n = \dfrac{n(n+1)}{2}$ → $\Theta(n^2)$
- $1 + \frac12 + \frac14 + \dots = 2$ (столбцы убывают вдвое → сумма $\le 2 \times$ первый)
- $1 + 2 + 4 + \dots + 2^k = 2^{k+1} - 1$ (растут вдвое → сумма $\approx 2 \times$ последний)
