## Рациональная дробь

**Рациональная (дробно-рациональная) функция** - дробь из многочленов:

$$R(x) = \frac{P(x)}{Q(x)} = \frac{a_0x^n + a_1x^{n-1} + \dots + a_{n-1}x + a_n}{b_0x^m + b_1x^{m-1} + \dots + b_{m-1}x + b_m}.$$

- $n \ge m$ - дробь **неправильная**;
- $n < m$ - дробь **правильная**.

Неправильная дробь = многочлен (целая часть) + правильная дробь (делением уголком):

$$\frac{P(x)}{Q(x)} = R(x) + \frac{S(x)}{Q(x)},$$

где $R(x)$ - целая часть, $S(x)$ - остаток от деления $P$ на $Q$, $\deg S = k < m$.

Пример:

$$\frac{x^4 - x^3 + 1}{x^2 + x + 2} = x^2 - 2x + \frac{4x + 1}{x^2 + x + 2}.$$

## Простейшие дроби

Правильная дробь раскладывается на **простейшие** дроби 4 типов:

$$1)\ \frac{A}{x-a}; \qquad 2)\ \frac{A}{(x-a)^n}\ (n \ge 2); \qquad 3)\ \frac{Mx+N}{x^2+px+q}; \qquad 4)\ \frac{Mx+N}{(x^2+px+q)^n}\ (n \ge 2).$$

(Здесь $x^2+px+q$ без действительных корней, $p^2 - 4q < 0$.)

## Теорема 1 (разложение на простейшие)

Пусть $\dfrac{P(x)}{Q(x)}$ правильная и

$$Q(x) = (x-a_1)^{k_1} \dots (x-a_i)^{k_i} (x^2+p_1x+q_1)^{l_1} \dots (x^2+p_jx+q_j)^{l_j}.$$

Тогда дробь **единственным образом** раскладывается в сумму простейших:

$$\frac{P(x)}{Q(x)} = \frac{A_1}{x-a_1} + \frac{A_2}{(x-a_1)^2} + \dots + \frac{A_{k_1}}{(x-a_1)^{k_1}} + \dots$$

$$+ \frac{B_1}{x-a_i} + \frac{B_2}{(x-a_i)^2} + \dots + \frac{B_{k_i}}{(x-a_i)^{k_i}} +$$

$$+ \frac{M_1x+N_1}{x^2+p_1x+q_1} + \frac{M_2x+N_2}{(x^2+p_1x+q_1)^2} + \dots + \frac{M_{l_1}x+N_{l_1}}{(x^2+p_1x+q_1)^{l_1}} + \dots$$

$$+ \frac{S_1x+T_1}{x^2+p_jx+q_j} + \frac{S_2x+T_2}{(x^2+p_jx+q_j)^2} + \dots + \frac{S_{l_j}x+T_{l_j}}{(x^2+p_jx+q_j)^{l_j}}, \qquad (1)$$

где все $A, B, M, N, S, T \in \mathbb{R}$.

Правило: множитель в степени $k$ даёт $k$ слагаемых, со степенями знаменателя от 1 до $k$. Над линейным множителем число, над квадратным - линейный многочлен.

Пример:

$$\frac{x^2+x+13}{(x-1)(x^2+4)^2x^3} = \frac{A}{x-1} + \frac{Bx+C}{x^2+4} + \frac{Dx+E}{(x^2+4)^2} + \frac{F}{x} + \frac{M}{x^2} + \frac{N}{x^3}.$$

Коэффициенты в (1) обычно ищут **методом неопределённых коэффициентов** или **методом частных значений**.

## Суть метода

1. Есть разложение правильной дроби $\dfrac{P(x)}{Q(x)}$ на простейшие по формуле (1).
2. Приводим простейшие дроби к общему знаменателю $Q(x)$ и приравниваем полученный числитель к $P(x)$.
3. Многочлены тождественно равны $\iff$ равны коэффициенты при одинаковых степенях $x$. Приравниваем их.
4. Получаем систему из $m$ линейных уравнений на $m$ неизвестных $A_1, \dots, A_{k_1}, \dots, B_1, \dots, B_{k_i}, M_1, N_1, \dots, M_{l_1}, N_{l_1}, \dots, S_1, T_1, \dots, S_{l_j}, T_{l_j}$.

## Пример 1

Разложить на простейшие дроби

$$\frac{7x^2 + 26x - 9}{x^4 + 4x^3 + 4x^2 - 9}.$$

**Раскладываем знаменатель:**

$$x^4 + 4x^3 + 4x^2 - 9 = (x^2 + 2x)^2 - 3^2 = (x^2 + 2x + 3)(x^2 + 2x - 3) = (x - 1)(x + 3)(x^2 + 2x + 3).$$

**Шаблон разложения:**

$$\frac{7x^2 + 26x - 9}{(x - 1)(x + 3)(x^2 + 2x + 3)} = \frac{A}{x - 1} + \frac{B}{x + 3} + \frac{Cx + D}{x^2 + 2x + 3}.$$

**К общему знаменателю** и отбрасываем его (равные дроби с одинаковыми знаменателями имеют равные числители):

$$7x^2 + 26x - 9 = A(x + 3)(x^2 + 2x + 3) + B(x - 1)(x^2 + 2x + 3) + (Cx + D)(x - 1)(x + 3).$$

**Раскрываем скобки:**

$$7x^2 + 26x - 9 = (A + B + C)x^3 + (5A + B + 2C + D)x^2 + (9A + B - 3C + 2D)x + (9A - 3B - 3D).$$

**Приравниваем коэффициенты:**

|степень|уравнение|
|---|---|
|$x^3$|$0 = A + B + C$|
|$x^2$|$7 = 5A + B + 2C + D$|
|$x^1$|$26 = 9A + B - 3C + 2D$|
|$x^0$|$-9 = 9A - 3B - 3D$|

$$A = 1, \quad B = 1, \quad C = -2, \quad D = 5.$$

**Ответ:**

$$\frac{7x^2 + 26x - 9}{x^4 + 4x^3 + 4x^2 - 9} = \frac{1}{x - 1} + \frac{1}{x + 3} + \frac{5 - 2x}{x^2 + 2x + 3}.$$
