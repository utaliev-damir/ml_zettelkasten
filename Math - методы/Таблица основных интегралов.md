## Базовые правила интегрирования

| Правило                        | Формула                                                                                                     |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------- |
| Интеграл нуля                  | $\displaystyle\int 0\,dx = C$                                                                               |
| Интеграл единицы               | $\displaystyle\int dx = x + C$                                                                              |
| Вынесение константы            | $\displaystyle\int C \cdot f(x)\,dx = C\displaystyle\int f(x)\,dx$                                          |
| Сумма / разность               | $\displaystyle\int \big(f(x) \pm g(x)\big)\,dx = \displaystyle\int f(x)\,dx \pm \displaystyle\int g(x)\,dx$ |
| Формула Ньютона–Лейбница       | $\displaystyle\int_a^b f(x)\,dx = F(b) - F(a)$                                                              |
| Интегрирование по частям       | $\displaystyle\int u\,dv = uv - \displaystyle\int v\,du$                                                    |
| По частям (развёрнутая запись) | $\displaystyle\int f(x)g'(x)\,dx = f(x)g(x) - \displaystyle\int f'(x)g(x)\,dx$                              |
| Замена переменной              | $\displaystyle\int f(\varphi(t))\varphi'(t)\,dt = \displaystyle\int f(x)\,dx,\quad x = \varphi(t)$          |
| Линейная замена                | $\displaystyle\int f(kx + b)\,dx = \dfrac{1}{k}F(kx + b) + C$                                               |
| Логарифмическая производная    | $\displaystyle\int \dfrac{f'(x)}{f(x)}\,dx = \ln\lvert f(x)\rvert + C$                                      |
| Производная под интегралом     | $\displaystyle\int f'(x)\,dx = f(x) + C$                                                                    |

## Свойства определённого интеграла

|Свойство|Формула|
|---|---|
|Совпадение пределов|$\displaystyle\int_a^a f(x)\,dx = 0$|
|Перестановка пределов|$\displaystyle\int_a^b f(x)\,dx = -\displaystyle\int_b^a f(x)\,dx$|
|Аддитивность по отрезку|$\displaystyle\int_a^b f(x)\,dx = \displaystyle\int_a^c f(x)\,dx + \displaystyle\int_c^b f(x)\,dx$|
|Линейность|$\displaystyle\int_a^b \big(\alpha f(x) + \beta g(x)\big)\,dx = \alpha\displaystyle\int_a^b f(x)\,dx + \beta\displaystyle\int_a^b g(x)\,dx$|
|По частям|$\displaystyle\int_a^b u\,dv = uv\Big\rvert_a^b - \displaystyle\int_a^b v\,du$|
|По частям (развёрнутая запись)|$\displaystyle\int_a^b f(x)g'(x)\,dx = f(x)g(x)\Big\rvert_a^b - \displaystyle\int_a^b f'(x)g(x)\,dx$|
|Чётная функция|$\displaystyle\int_{-a}^{a} f(x)\,dx = 2\displaystyle\int_0^a f(x)\,dx$|
|Нечётная функция|$\displaystyle\int_{-a}^{a} f(x)\,dx = 0$|
|Периодическая, период $T$|$\displaystyle\int_a^{a+T} f(x)\,dx = \displaystyle\int_0^{T} f(x)\,dx$|
|Оценка модуля|$\left\lvert\displaystyle\int_a^b f(x)\,dx\right\rvert \le \displaystyle\int_a^b \lvert f(x)\rvert\,dx$|

## Подсказки по методам

|Тип подынтегральной функции|Приём|
|---|---|
|$P(x)e^{kx}$, $P(x)\sin kx$, $P(x)\cos kx$|По частям, $u = P(x)$|
|$P(x)\ln x$, $P(x)\arctan x$, $P(x)\arcsin x$|По частям, $u$ — логарифм или аркфункция|
|Правило выбора $u$|**ЛИАТП**: логарифм → аркфункция → алгебраическая → тригонометрическая → показательная|
|Дробь с квадратным трёхчленом|Выделить полный квадрат: $ax^2 + bx + c = a\left(x + \frac{b}{2a}\right)^2 + \left(c - \frac{b^2}{4a}\right)$|
|Правильная рациональная дробь|Разложение на простейшие дроби|
|$R(\sin x, \cos x)$|Универсальная подстановка $t = \tan\dfrac{x}{2}$: $\sin x = \dfrac{2t}{1+t^2}$, $\cos x = \dfrac{1-t^2}{1+t^2}$, $dx = \dfrac{2\,dt}{1+t^2}$|
|Нечётность по $\sin x$|Подстановка $t = \cos x$|
|Нечётность по $\cos x$|Подстановка $t = \sin x$|
|Чётность по $\sin x$ и $\cos x$|Подстановка $t = \tan x$|
|$\sqrt{a^2 - x^2}$|$x = a\sin t$|
|$\sqrt{a^2 + x^2}$|$x = a\tan t$|
|$\sqrt{x^2 - a^2}$|$x = \dfrac{a}{\cos t}$|
|$\sqrt[n]{\dfrac{ax+b}{cx+d}}$|$t = \sqrt[n]{\dfrac{ax+b}{cx+d}}$|
