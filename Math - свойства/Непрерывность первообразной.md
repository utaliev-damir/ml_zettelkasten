## Формулировка

Докажите, что функция $$F(x) = \int_a^x f(t)\thinspace dt, \quad x \in [a;b]$$ непрерывна на $[a;b]$.

Обозначение: $F$ здесь - не первообразная в смысле $F'=f$, а просто функция, заданная интегралом с переменным верхним пределом. Является ли $F$ первообразной для $f$ - отдельный вопрос, требующий дополнительных условий (см. "Следствия").

## Условия

Предположения, при которых утверждение верно.

- $f$ интегрируема по Риману на $[a;b]$. Отсюда автоматически её ограниченность: существует $M>0$ такое, что $|f(t)|\le M$ для всех $t\in[a;b]$.
- Непрерывность или дифференцируемость $f$ не требуются - утверждение верно и для разрывной $f$.

## Идея доказательства

Доказательство идёт прямо по $\varepsilon$-$\delta$ определению непрерывности, без обращения к теоремам о пределах. Разность значений $F$ в двух точках по аддитивности интеграла **равна** интегралу по промежутку между этими точками, а такой интеграл оценивается через $M\cdot(\text{длина промежутка})$. То есть близость точек напрямую контролирует близость значений, и по заданному $\varepsilon$ нужное $\delta$ выписывается явной формулой $\delta=\varepsilon/M$.

## Доказательство

Пусть $x_0\in[a;b]$ - произвольная точка. Нужно показать: $$\forall \varepsilon>0 \quad \exists \delta>0: \quad \forall x\in[a;b], \ |x-x_0|<\delta \ \Rightarrow \ |F(x)-F(x_0)|<\varepsilon.$$

**Шаг 1. Разность сводится к одному интегралу.**

По определению $F$ и по аддитивности интеграла по промежутку интегрирования: $$F(x)-F(x_0) = \int_a^x f(t)\thinspace dt - \int_a^{x_0} f(t)\thinspace dt = \int_{x_0}^{x} f(t)\thinspace dt.$$

Это равенство, а не оценка: интегралы по $[a;x_0]$ сокращаются точно.

**Шаг 2. Оценка через ограниченность $f$.**

Интегрируемость $f$ на $[a;b]$ влечёт её ограниченность, поэтому $$|F(x)-F(x_0)| = \left|\int_{x_0}^{x} f(t)\thinspace dt\right| \le M\thinspace |x-x_0|.$$

Неравенство нестрогое: при $f\equiv M$ здесь равенство.

**Шаг 3. Выбор $\delta$.**

По заданному $\varepsilon>0$ положим $$\delta = \frac{\varepsilon}{M}.$$

Тогда для любого $x\in[a;b]$ с $|x-x_0|<\delta$: $$|F(x)-F(x_0)| \le M\thinspace|x-x_0| < M\delta = \varepsilon.$$

Строгость берётся из условия $|x-x_0|<\delta$, поэтому итоговое неравенство строгое.

Точка $x_0$ была произвольной, значит $F$ непрерывна на $[a;b]$. $\blacksquare$

## Следствия

- Найденное $\delta=\varepsilon/M$ не зависит от точки $x_0$, значит непрерывность равномерная на $[a;b]$.
- Оценка шага 2, $|F(x)-F(x_0)|\le M|x-x_0|$, это условие Липшица с константой $M$ - свойство более сильное, чем равномерная непрерывность.
- Утверждение верно для любой интегрируемой $f$, включая разрывную: интегрирование "сглаживает" функцию. Например, для ступеньки $f$ функция $F$ выходит непрерывной кусочно-линейной.
- Дифференцируемость $F$ и равенство $F'=f$ - отдельное, более сильное утверждение. Одной интегрируемости $f$ для него недостаточно: у ступеньки $F$ непрерывна, но в точке скачка не дифференцируема. Требуется непрерывность $f$ в соответствующей точке.
