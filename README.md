# ШАД / ML Zettelkasten

Хранилище Obsidian для подготовки к ШАД и изучения ML. Открывать нужно через `Open folder as vault`, иначе не будут работать ссылки, шаблоны и dataview.

## Как всё устроено

Папка определяет тип заметки: определение, теорема, модель ML и так далее. Префиксы `Math -`, `Algos -`, `ML -` добавлены к тем типам, которые встречаются только в одном разделе.

Тема заметки задаётся не папкой, а полями `раздел` и `подраздел` во frontmatter. Оба поля — списки ссылок на файлы из `_структура/`. Значения выбираются из выпадающего списка плагина Metadata Menu, вручную их вводить не нужно.

Поэтому одна заметка может относиться сразу к нескольким темам. Например, заметка про градиентный спуск лежит в `Math - методы/`, а в поле раздела у неё указаны и матан, и ML, так что она попадёт на обе страницы разделов.

## Типы заметок

| Папка | Что это |
|---|---|
| `Math - определения/` | Определение объекта |
| `Math - свойства/` | Свойство |
| `Math - теоремы/` | Теорема с доказательством |
| `Math - методы/` | Подход к решению класса задач |
| `Algos - определения/` | Асимптотика, сложность, теория |
| `Algos - алгоритмы/` | Алгоритм с псевдокодом и оценкой сложности |
| `Algos - структуры данных/` | Тип данных и операции над ним |
| `ML - модели/` | Модель, которая делает предсказания |
| `ML - методы/` | Приём вокруг обучения, а не сама модель |
| `ML - концепции/` | Теоретические понятия |
| `ML - оценивание/` | Функции потерь и метрики |
| `Задачи/` | Решённая задача с разбором |
| `Сигналы/` | Признак в условии, указывающий на метод |
| `Code - понятия/` | Понятие языка, библиотеки или инструмента |
| `Code - приёмы/` | Рабочий рецепт и подвох, который с ним связан |

У задач и сигналов префикса нет, потому что они относятся к нескольким разделам сразу.

## Служебные папки

| Папка | Назначение |
|---|---|
| `_структура/разделы/` | По файлу на раздел. Собирает заметки dataview-запросами |
| `_структура/подразделы/` | По файлу на подраздел, имя в формате `раздел - подраздел` |
| `_структура/Шадборд.md` | Дашборд: задачи на повтор, статистика, аудит связей |
| `_шаблоны/` | Шаблоны для каждого типа заметок |
| `_файлы/` | Вложения: изображения и схемы |
| `_недели/` | Недельные планы и рефлексия |
| `Rest/` | Старые заметки, не переведённые в систему |

Сейчас 9 разделов и 41 подраздел, полный список — в `_структура/Разделы и подразделы.md`. Новый подраздел стоит заводить, когда набралось хотя бы 5 заметок, которым тесно в существующем. Больше 6 подразделов на раздел лучше не делать.

## Поле «формат» у задачи

| Значение | Когда использовать |
|---|---|
| `доказательство` | Доказать, проверить, обосновать |
| `вывод` | Получить формулу или оценку |
| `численная` | Посчитать конкретное значение |
| `код` | Реализовать алгоритм или функцию |

## Плагины

Нужны Templater, Dataview и Metadata Menu. В настройках Templater папка шаблонов должна быть указана как `_шаблоны`.
