## Условие
Вычислить $\displaystyle\int_{\pi}^{2\pi} e^x \sin x\,dx$.
 
## Сигналы
* Произведение $e^x$ и $\sin x$.
* Ни один множитель не упрощается при дифференцировании.
## Основной метод
[[Циклическое интегрирование по частям]]
 
## Ключевая идея
Дважды проинтегрировать по частям, чтобы исходный интеграл вернулся, и решить уравнение относительно $I$.
 
## План решения
1. Обозначить $I = \int e^x \sin x\,dx$.
2. По частям: $f = \sin x$, $g' = e^x$.
3. По частям ещё раз: $f = \cos x$, $g' = e^x$ (та же роль у $e^x$).
4. Выразить $I$, подставить пределы, проверить знак.
## Ошибки / тупики
Пытался выбрать $g'$ так, чтобы избавиться от $e^x$. После первого шага казалось, что ничего не упростилось, и было непонятно, зачем продолжать.
 
## Инсайт
Интегрирование по частям не обязано упрощать интеграл: оно может **вернуть исходный**, и тогда решение сводится к уравнению. Роль $e^x$ на обоих шагах должна быть одинаковой.
 
## Вычисления
$$I = e^x \sin x - \int e^x \cos x\,dx = e^x \sin x - e^x \cos x - I$$
$$I = \frac{e^x(\sin x - \cos x)}{2} + C$$
$$\left.\frac{e^x(\sin x - \cos x)}{2}\right|_{\pi}^{2\pi} = -\frac{e^{2\pi}}{2} - \frac{e^{\pi}}{2} = -\frac{e^{2\pi} + e^{\pi}}{2}$$
