## Условие
Вычислить $I_n = \displaystyle\int_0^{\pi} \sin^n x\,dx$.
 
## Сигналы
* Параметр $n$ в степени: считать напрямую нельзя, нужна рекуррентная формула.
* После интегрирования по частям исходный интеграл возвращается.
## Основной метод
Интегрирование по частям → рекуррентное соотношение.
 
## Ключевая идея
Отщепить один синус: $\sin^n x = \sin^{n-1}x \cdot \sin x$, а после интегрирования по частям заменить $\cos^2 x = 1 - \sin^2 x$, чтобы остались только синусы.
 
## План решения
1. По частям: $f = \sin^{n-1}x$, $g' = \sin x$, $g = -\cos x$.
2. Граничный член обнуляется, остаётся $(n-1)\int \sin^{n-2}x\cos^2 x\,dx$.
3. $\cos^2 x = 1 - \sin^2 x$ → получить $I_n = (n-1)(I_{n-2} - I_n)$.
4. Выразить $I_n$, найти $I_0$, $I_1$, раскрутить рекурсию.

## Ошибки / тупики
Было непонятно, как $\int \sin^{n-2}x\cos^2 x\,dx$ превращается в $I_{n-2} - I_n$. Разобрался: раскрыть скобки $\sin^{n-2}x(1-\sin^2 x) = \sin^{n-2}x - \sin^n x$ и узнать в интегралах обозначения $I_{n-2}$ и $I_n$.
 
## Инсайт

Интегралы с параметром $n$ решаются не вычислением, а связью $I_n$ с $I_{n-2}$. 
 
## Вычисления

По частям:
$$f = \sin^{n-1}x,\quad g' = \sin x,\quad f' = (n-1)\sin^{n-2}x\cos x,\quad g = -\cos x$$

$$I_n = \underbrace{\Big[-\sin^{n-1}x\cos x\Big]_0^\pi}_{0,\ \text{т.к. } \sin 0 = \sin\pi = 0} + (n-1)\int_0^\pi \sin^{n-2}x\cos^2 x\,dx$$

Убираем косинус через $\cos^2 x = 1 - \sin^2 x$:
$$\sin^{n-2}x\cos^2 x = \sin^{n-2}x - \sin^n x$$

$$I_n = (n-1)\big(I_{n-2} - I_n\big)$$

Выражаем $I_n$:
$$n\,I_n = (n-1)I_{n-2} \quad\Rightarrow\quad I_n = \frac{n-1}{n}\,I_{n-2}$$

Шаг рекурсии 2: чётные $n$ сводятся к $I_0$, нечётные к $I_1$.

$I_0$ — интеграл от единицы, то есть длина отрезка:
$$I_0 = \int_0^\pi 1\,dx = \pi$$

$I_1$ — площадь под одной аркой синуса:
$$I_1 = \Big[-\cos x\Big]_0^\pi = -\cos\pi + \cos 0 = 1 + 1 = 2$$

Раскручиваем рекурсию:
$$I_4 = \frac{3}{4}\cdot\frac{1}{2}\cdot I_0 = \frac{3\pi}{8}, \qquad I_5 = \frac{4}{5}\cdot\frac{2}{3}\cdot I_1 = \frac{16}{15}$$

Сверху копится $(n-1)!!$, снизу $n!!$:
$$n \text{ чётное: } I_n = \pi\cdot\frac{(n-1)!!}{n!!}, \qquad n \text{ нечётное: } I_n = 2\cdot\frac{(n-1)!!}{n!!}$$

Проверка:
$$I_2 = \frac{\pi}{2}, \qquad I_3 = \frac{4}{3}\ ✓$$
